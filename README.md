# Colombia por Descubrir

Blog estático desarrollado para la actividad **Creación de un blog** de la asignatura Desarrollo de Aplicaciones en Red.

El sitio presenta tres artículos turísticos sobre destinos imperdibles de Colombia: Eje Cafetero, Medellín y San Andrés.

## Tecnologías utilizadas
- [Astro](https://astro.build/): Framework para la generación del sitio estático.
- HTML5 y CSS3: Estructura y diseño adaptativo (Responsive Design).
- Git y GitHub: Control de versiones.
- GitHub Actions y GitHub Pages: Despliegue y alojamiento web.

## Iniciar en el computador (Entorno local)

Requisitos: Tener instalado Node.js (versión 22 o superior) y npm.

```bash
# Instalar las dependencias del proyecto
npm install

# Iniciar el servidor de desarrollo local
npm run dev
